# Manual Blood Pressure AR Trainer Project Charter

## Project Name
Manual Blood Pressure AR Trainer — Galaxy XR / Unity / Android

## Project Objective
Build an augmented reality training application for manual blood pressure measurement on Galaxy XR, using Unity for the XR experience and Android Studio for Android build, deployment, debugging, and release coordination.

## Problem Statement
Learners need a structured, repeatable, and immersive way to practice manual blood pressure measurement. The application should guide trainees through the procedure in AR, validate steps, provide corrective feedback, and support pilot deployment on Galaxy XR hardware.

## Goals
- Deliver an MVP training flow for manual blood pressure measurement.
- Support Galaxy XR headset deployment and testing.
- Use Unity as the primary XR development environment.
- Use Android Studio for Android packaging, debugging, and device integration.
- Provide a project structure that supports coordinated planning, implementation, QA, and release management.

## Non-Goals
- Full LMS integration in the first MVP.
- Multi-procedure support beyond manual blood pressure training.
- Instructor portal or analytics dashboard in the first release.
- Networked multi-user experiences in the first release.

## Success Criteria
- A user can complete the manual blood pressure training scenario end to end.
- The app provides step guidance, validation, and final scoring/feedback.
- The application builds successfully through the Unity-to-Android workflow.
- The application is deployed and tested on Galaxy XR hardware.
- The backlog and roadmap are maintained in GitHub Project 1.

## Stakeholder Areas
- Product / Instructional Design
- Unity / XR Engineering
- Android Engineering
- 3D Content / UX
- QA / Device Testing
- Release Management

## Suggested GitHub Project Fields
- Status: Backlog, Ready, In Progress, Blocked, In Review, QA / Device Test, Done
- Workstream: Product, Unity/XR, Android, 3D Content, QA, Release
- Priority: P0, P1, P2
- Phase: Discovery, Setup, Prototype, MVP, Validation, Release

## Initial Epics
1. Define MVP training scenario.
2. Set up Unity XR application foundation.
3. Set up Android Studio integration and build pipeline.
4. Implement AR interaction system.
5. Build manual blood pressure training workflow.
6. Create instructional UI, guidance, and feedback.
7. Test and optimize on Galaxy XR hardware.
8. Prepare pilot release.
